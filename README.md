# Vamanan GPT

> Where the smallest step holds the world.

Vamanan GPT is an immersive cultural storyteller rooted in Kerala's Onam traditions. It brings the story of Vamanan and King Mahabali into an intimate chat experience, pairing a small curated knowledge base with a visual interpretation of the three cosmic steps.

## What makes it different

- **A living archive** — answers connect Vamanan, Mahabali, Onam, Trivikrama, and Kerala's oral traditions.
- **The three steps, made visible** — an interactive visual moves from Earth to the Heavens to the final offering of the self.
- **Memory without a login** — conversations are saved for the browser and restored when the visitor returns.
- **A Kerala-first visual language** — pookkalam geometry, palm-leaf warmth, mural reds, temple greens, and editorial typography.

## Run locally

```bash
npm install
npm run dev
```

The app uses the configured Supabase project for conversation memory. The browser uses an anonymous session identifier, so no account is needed to explore the experience.

## The story

Vamanan is the fifth avatar of Vishnu: the small brahmachari who asks King Mahabali for three paces of land, then reveals a cosmic form. The first step covers the earth. The second covers the heavens. For the third, Mahabali offers his own head.

In Kerala, Onam is the annual return of Mahabali to his people — a celebration of generosity, belonging, and the promise that a good story can return whenever it is remembered.
